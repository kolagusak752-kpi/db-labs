1. Призначення системи

Система працює як платформа самообслуговування для аматорських турнірів для будь-яких ігор. Будь-який користувач може створити команду, приєднатися до команди, подати заявку на участь в турнірі, стати організатором власного турніру

2. Які дані зберігає система

Користувачі: базова інформація (email, пароль, нікнейм)

Команди: назва команди та посилання на користувача-капітана

Склад команди: які саме гравці входять до команди 

Турніри: назва, гра, хто організатор та яка сума призового фонду

Учасники турніру: список команд, які подали заявку на конкретний турнір

Зустрічі: які команди грають між собою, посилання на наступню зустріч для того щоб просунути команду переможця

Матчі: окремі зіграні карти в рамках однієї зустрічі

Статистика: показники гравця (вбивства/смерті/асисти) за кожен окремий матч

3. Бізнес-логіка

Користувач, який створює команду, автоматично стає її капітаном і отримує права на управління

Гравці прив'язуються до команди через проміжну таблицю

Організатор турніру сам вказує та оплачує призовий фонд, ця сума просто фіксується цифрою в таблиці турніру

Турнірна сітка генерується системою миттєво як набір порожніх зустрічей, які пов'язані між собою (переможець попереднього матчу автоматично переходить у наступний порожній слот)

Статистика KDA рахується не за весь турнір чи зустріч, а строго за кожну зіграну картує

Команда не може подати заявку на турнір, якщо в її складі не вистачає гравців

Нікнейм гравця та назва команди є унікальними на всій платформі

4. Що можуть робити користувачі

Реєструватися та створювати власні команди

Входити до команд інших користувачів

Подавати заявки на участь у турнірах

Створювати власні турніри та використовувати автоматичну генерації сітки

Вносити результати зіграних матчів для просування команд по сітці
